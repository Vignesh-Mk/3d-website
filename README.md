# "Nowhere Shack" — Abstract Cartoon 3D Portfolio

An interactive, 90s-cartoon styled namesake portfolio website inspired by *Courage the Cowardly Dog* and *Oggy and the Cockroaches*. Built with **React 19**, **Three.js (@react-three/fiber & @react-three/drei)**, **Tailwind CSS**, and **Zustand**.

---

## 🏚️ Features & Interactive Props

* **💻 Sarcastic CRT Computer (QA / SDET Hub):**
  * Dynamic canvas ASCII face `(¬_¬)` that blinks and smirks on hover.
  * Interactive phosphor-green retro terminal with live CI/CD test runner simulation, test metrics, and automation frameworks.
* **⛓️ Rattling Padlocked Trapdoor (Game Dev Vault):**
  * Cellar door bound by heavy chains and an oversized padlock that physically rattles.
  * Dimensional void modal highlighting Unity 6 (URP) projects, C#, custom shaders, and itch.io playable links.
* **🧊 Bulging Vintage Fridge (Skills & Tech Stack):**
  * Shivers and leaks cold light under pressure.
  * Interactive food-shelf inspector filtering skills across Languages, Test Tools, DevOps, and 3D graphics.
* **👀 Crooked Eyes Portrait Wall (Academics & Certifications):**
  * Eyeballs inside framed portraits mathematically track your mouse cursor in real-time.
  * Expands into MCA degree credentials and ISTQB/AWS certified badges.
* **💥 Red "DO NOT PRESS" ACME Plunger Button (About & Resume):**
  * Squashes rubber-band style on press with celebratory cartoon confetti.
  * Displays engineer dossier, social contacts, and 1-click CV print/download.
* **📄 Recruiter-Friendly 2D Clean View:**
  * Persistent button (`"Switch to Clean View"`) bypasses 3D completely into an accessible, responsive, printable single-page resume.
* **🔊 Built-in Web Audio Procedural Synthesizer:**
  * Generates cartoon boings, squishes, clicks, terminal beeps, and fanfares natively with zero external audio assets needed. Sound toggle included.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm run preview
```

## 🛠️ Customizing Your Content

All portfolio data (name, bio, stats, test frameworks, game builds, skills, and education) is centralized in:
`src/data/portfolioData.js`

Simply update the fields in that file to reflect your personalized career milestones!
